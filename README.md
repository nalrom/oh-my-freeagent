# oh-my-freeagent

**Free Specialized Agents for OpenCode**

No API keys. No credit cards. Just free AI.

oh-my-freeagent is a configuration overlay for OpenCode that maps every agent role to genuinely free AI models. Same agents, same workflows — zero cost.

## Quick Start

1. Copy `oh-my-freeagent.json` to your OpenCode packages directory
2. Restart OpenCode
3. Done
